# Security

Launcher Lag Guard uses an Android Accessibility service. Reports involving an
unexpected gesture, access outside the Recents screen, package impersonation,
or unintended data exposure should not be filed as a public issue.

Use GitHub's private security-advisory feature for this repository. Include the
affected version, device and firmware, reproduction steps, and relevant logs.

Do not include personal screen content, account data or full UI dumps in a
report.
